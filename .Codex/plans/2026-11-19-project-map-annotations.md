# 地區專案、事件座標與地圖標註

## 使用者要求

左側維持地區專案。雨量站屬於專案的事件圖卡，每張事件可有座標。專案地圖可以放點、線、面標註資料，並實際建立幾筆事件。

後續補充：整站必須有兩個地圖層級：地區專案總覽地圖 → 專案內地圖。已請原 WebGIS 專家重新檢視整站架構。原有的事件與標註工作繼續納入此兩層架構。

最新補充：兩層地圖除了座標點，也要直接顯示名稱；調整目前示範資料，避免專案與事件使用同一位置。原調查事件未知座標不得憑空改寫，共用位置應將名稱集中呈現而不互相覆蓋。

## 成功條件

- [x] 左側只有地區專案，雨量站不再是專案建立類型。
- [x] 總覽只顯示專案，點選專案進入獨立工作區；可返回總覽並以網址直接開啟專案。
- [x] 專案內地圖只顯示該專案的事件及圖層，不混入其他專案的標記。
- [x] 專案內可建立有獨立座標的雨量站事件，地圖、篩選、編輯及閱讀均可使用。
- [x] 所選專案支援點、線、面標註繪製、命名、保存、定位、刪除與 GeoJSON 匯入／匯出。
- [x] 標註隨專案切換，不受事件日期篩選影響；匯出專案檔包含標註。
- [x] 建立清楚標示為操作示範的專案與數筆事件，不改動原調查資料。
- [ ] 新增驗證與操作測試通過，桌機／手機驗收，發布並驗證正式網站。
- [ ] 總覽及專案地圖直接顯示名稱，共用座標的事件均可選擇。
- [ ] 示範專案、三筆事件及點線面移到分離位置，原調查資料保持原樣。

## 步驟

- [x] 先補雨量站事件與標註驗證測試，確認原實作無法滿足。
- [x] 實作專案標註資料表及受保護 API，保留既有事件與專案資料。
- [x] 依 WebGIS 專家建議重整總覽與專案工作區的導覽、地圖與圖層。
- [x] 修正左側與事件分類；加入沿用現有配色的地圖繪製及標註清單。
- [x] 完成匯入、匯出、錯誤狀態與跨專案測試。
- [ ] 建立示範事件與點線面標註，驗收、發布及確認資料保存。

## 設計與範圍

依 Felt 的瀏覽／繪製模式及 ArcGIS StoryMaps 的簡潔點線面工具安排操作，沿用現有 Leaflet 與色彩，不新增繪圖套件。GeoJSON 匯入使用 WGS84 經度、緯度；事件手輸座標仍提供 WGS84 與 TWD97。示範資料必須明示非實際觀測資料。

參考：https://help.felt.com/getting-started/tour-the-interface 、https://doc.esri.com/en/arcgis-storymaps/latest/author-and-share/add-maps.html 、https://leafletjs.com/examples/geojson/
