# 依時間逐筆閱覽與事件鳥瞰

## 使用者要求與確認

事件時間軸應有依順序跳往地圖上各點的閱覽／鳥瞰功能，表達時間發展，而非鬆散資料搜集。使用者已選擇「逐筆前進／後退＋鳥瞰」，本次不加自動播放。

後續要求：標註也要以圖卡顯示名稱、說明、類型與座標資訊；事件與標註要清楚區分。原先空心圓太淡，改成明顯的實心藍色方形／菱形點，線面也加強。

## 行為與成功條件

- [x] 事件時間軸由舊到新排序，同時間以建立時間及 ID 穩定排序，不改寫資料。
- [x] 以開始導覽、上一筆、下一筆走訪目前篩選事件；顯示序號、時間及名稱，選中圖卡及地圖點並移動地圖。
- [x] 地圖標記與名稱包含時間順序編號；共享位置仍可逐筆閱覽，並明示沿用地區座標。
- [x] 鳥瞰只涵蓋目前篩選的事件，保留導覽游標，下一筆可繼續；不把事件順序畫成實際路徑。
- [x] 點圖卡／地圖名稱／定位均會連動導覽焦點；閱讀區也能上一筆、下一筆及返回鳥瞰。
- [x] 手機有相同導覽操作；按鈕不遮住地圖點；尊重減少動態效果偏好。
- [x] 篩選、刪除及切換專案後不留下錯誤焦點，路由與地圖清理維持正常。
- [x] 標註提供資訊圖卡，點地圖標註可開啟所屬卡片，手機也可使用。
- [x] 事件使用時間編號圓點；標註採醒目的實心藍色點、加強線面與獨立圖卡樣式。
- [x] 測試、桌機與手機實際驗收、發布及正式站驗證。

## 步驟

- [x] 先寫排序及導覽行為測試，確認目前缺少功能。
- [x] 建立共用時間排序與簡潔導覽控制，整合事件焦點、地圖及閱讀區。
- [x] 加上時間順序編號、選中狀態、鳥瞰及篩選／專案切換處理。
- [x] 檢查地圖尺寸、共用座標、閱讀區與手機操作，通過必要回歸測試。
- [x] 發布並以既有三筆分散示範事件驗證，保留原資料。

## 範圍

沿用 Vue 與 Leaflet，不新增後端欄位、依賴或資料，不自動播放，也不推定事件間存在實際移動路徑。地圖下方保留導覽區域，避免遮住點位。
