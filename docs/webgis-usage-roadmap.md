# 地圖與事件紀錄操作

## 地區專案與事件

總覽每個標記代表一個地區專案。點地圖名稱或清單進入專案，可直接分享 `#/projects/:id` 網址，並使用「所有專案」返回。

左側只有事件時間軸與新增入口。按「新增事件」填寫臺灣時間、名稱、類型、說明、來源與可選媒體；每張事件卡可有自己的座標。也可按「地圖選點新增事件」，再點地圖設定位置。手機保留地圖／時間軸切換，新增入口持續可用。

座標可填 WGS84 經緯度，或以 TWD97 / EPSG:3826 輸入公尺座標並定位預覽。舊事件沒有個別座標時沿用地區位置，會明示來源，不編造觀測位置。雨量站是專案中的一種事件類型，不會新增到地區專案清單。

## 時間導覽

時間軸由舊到新排列，地圖圓點與名稱顯示相同編號。「開始導覽／上一筆／下一筆」移到事件位置並選中圖卡；「閱讀內容」開啟事件，閱讀區也可逐筆切換。

「鳥瞰事件」涵蓋目前篩選結果，保留導覽進度，下一筆可繼續。事件之間不畫實際移動路線，不自動播放。共用位置仍可逐筆閱讀，並列出所有名稱。密集標記或很長的名稱仍可能互相遮擋，可逐筆聚焦查看完整內容。

日期／類型篩選同步影響時間軸與事件點，日期採臺灣時區。建立／最後修改時間由系統產生，舊資料缺值時標示未記錄。

## 底圖與資料圖層

地圖右上「圖層」集中管理兩組內容：

- **底圖**：基本地圖／衛星影像，兩者擇一。
- **資料圖層**：事件是必要圖層，固定顯示（仍可篩選事件）；標註與地質圖為可選套疊，預設收起，可分別開關、同時顯示。

事件為暖色時間編號圓點；標註為實心藍色方點與藍色線面。縮放與「專案範圍」共用左下同一組按鈕，沒有額外右下定位按鈕、瀏覽／事件模式工具列或左下圖例。

地質圖使用經濟部地質調查及礦業管理中心的官方 1:50,000 臺灣地質圖。開啟後可調整不透明度，查看來源與比例尺；載入失敗可關閉或重新載入，不影響事件。來源影像不寫入事件／標註，也不加入 KML 匯出。[官方介接說明](https://geomap.gsmma.gov.tw/gsb108-1/list_service.cfm)。

## 標註管理與 KML／KMZ

從圖層選單按「管理標註」，在地圖側開啟點、線、面資訊卡及繪製工具；手機使用地圖上的浮動面板。點圖形或名稱也可打開對應圖卡。圖卡顯示名稱、說明、幾何類型及 WGS84 位置／範圍，可定位與刪除，不進入事件時間軸。

- 點：按「標點」，在地圖選位置。
- 線：按「畫線」，至少選兩個不同位置後完成。
- 面：按「畫面」，至少選三個不同頂點後完成，系統封閉外框。
- 可復原一點或取消；取消後回到標註管理。繪製與事件選點互斥。

匯入接受 **KML／KMZ**，預覽待新增名稱及類型後再儲存。保留名稱、純文字說明、點線面及內環；MultiGeometry 拆成編號圖卡。高程、樣式、附件及外部連結不載入，含 NetworkLink／Overlay 等不支援內容時會明確拒絕。

KML 最多 2 MB，KMZ 最多 5 MB；ZIP 最多 32 條目、解壓最多 8 MB。單次最多 100 筆、每筆 2000 座標、合計 10000 座標，轉換後資料上限 480 KB。整份通過驗證才儲存，不寫入部分成功資料。

匯出可選 KML 或 KMZ，包含該專案全部有效標註，不受事件日期／類型篩選影響。超過單次匯入上限的大檔，重新匯入前需分批。API 內部維持原有 GeoJSON 幾何，舊資料不需重建。

## 網頁、照片與 PDF

網頁與照片分頁呈現，閱讀區預設占桌機 75%，可展開全寬；手機為全寬。只有文字與座標的事件直接顯示內容，不留下空白媒體區。

網址會依副檔名、已知分享連結及實際回應類型判斷。PDF 使用專用閱讀器，支援 `#page=`、換頁、指定頁碼、符合寬度、放大、本頁文字及原檔入口；上限 50 MB，失敗時可重試或開原檔。

Google Drive 保留原檔分享權限；調整分享後可重新載入。NCDR 等限制內嵌的網站提供原網站入口，沒有繞過來源限制。

## 保存與示範資料

新增、刪除、匯出等操作沿用管理員驗證；新增另需網站驗證。專案 JSON 是事件與標註紀錄備份，與 KML／KMZ 地圖交換分開。金鑰只在目前工作區記憶體使用，不寫進瀏覽器儲存。

「操作示範｜事件與圖層」包含三筆不同位置的示範事件及點、線、面各一筆；坐標與內容只供操作展示，不代表實際站網、雨量、災情或施工。官方地質圖則是獨立外部來源，不是示範標註。
